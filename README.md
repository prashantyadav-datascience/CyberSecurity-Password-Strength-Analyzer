## 📌 Project Overview

**Cybersecurity Password Strength & Breach Risk Analyzer** is an end-to-end Python and Machine Learning project designed to evaluate password strength and estimate security risk.

The system analyzes password characteristics such as length, character diversity, digits, uppercase/lowercase characters and special characters, and uses machine learning to generate a password security prediction.

The project provides an interactive **Streamlit dashboard** where users can enter a password and receive an easy-to-understand security analysis.

---

## 🎯 Problem Statement

Weak and predictable passwords are one of the common causes of account compromise.

Traditional password strength checkers generally rely only on fixed rules. This project explores a **Machine Learning-based approach** to analyze password characteristics and provide a more informative security assessment.

### Objective

- Analyze password characteristics
- Predict password strength
- Estimate security risk
- Visualize prediction probabilities
- Provide an interactive dashboard
- Generate a downloadable security report
